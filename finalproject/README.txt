Required python libraries:
	socket, cryptodome, pwinput, bcrypt 

	msgpack, sys, os, json, datetime, time

Steps:
	1. Open 2 or 3 terminals and cd into the folder with this readme

	2. CD into the "bank" file in one terminal

	3. CD into the "atm1" and/or the "atm2" in the other terminal(s)
	
	4. Run the "bank.py" file in the first terminal

	5. Run the "atm1.py" and/or "atm2.py" file in the other terminal(s)
	with either "RSA" or "DSA" as the command line argument

	6. Enter user name and password for the account on the atm client
	I have 4 that work:
				123456 meow
 				654321 bark
  				111111 moo
				555555 ribbit
	7. Select any option you want thats displayed on the terminal
	Also you can view the bank.py communications with the atm in that terminal

	8. Enter "5" to close the atm clients and click "ctrl c" to close the bank
